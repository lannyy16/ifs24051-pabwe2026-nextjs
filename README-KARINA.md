# PABWE 2026 - Next.js - Karina Putri Sion

Project ini disusun untuk Tugas 2 PABWE dengan Next.js + TypeScript, menggunakan struktur dan pola implementasi proyek referensi yang diberikan untuk dipelajari dan diadaptasi.

## Jalankan

```bash
bun install
bun run dev
```

Buka `http://localhost:3000`.

## Environment

Salin `.env.example` menjadi `.env` jika diperlukan.
