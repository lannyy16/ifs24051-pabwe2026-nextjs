# ifs24051-pabwer2026-nextjs

Aplikasi Postingan menggunakan Next.js + TypeScript untuk PABWE 2026, dengan Bun, Tailwind CSS v4, Redux Toolkit, Vitest, SweetAlert2, React Icons, dan Delcom Open API.

## Menjalankan

```bash
bun install
bun run dev
```

Default port: `APP_PORT=3000`.

## Production

```bash
bun run build
bun run start
```

## Test

```bash
bun run test
bun run test:coverage
```

Coverage threshold dikonfigurasi 100% untuk lines, functions, branches, dan statements.
